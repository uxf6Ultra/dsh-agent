# 使用规范版本管理

> 本目录存放 `docs/usage-spec` 分支上的使用规范版本。
> 原则：**每次大变动 / 新规范 / 调用修改，新增一个版本，互不覆盖。**

## 版本规则

| 项 | 规则 |
|----|------|
| 版本命名 | `v<主>.<次>`，如 `v1.0`、`v1.1`、`v2.0` |
| 文件命名 | `usage-spec-v<版本>.md` |
| 新增版本 | 大变动时**新建**文件，**不修改**旧版本 |
| 版本记录 | 每次新增须同步更新 `CHANGELOG.md` |
| Git 标记 | 重要版本同时打 tag：`git tag v1.0` |

## 版本历史

| 版本 | 日期 | 说明 |
|------|------|------|
| [v1.1](usage-spec-v1.1.md) | 2026-10-27 | 新增 Skill 打包：如何使用本仓库（`dsh-dfy-agent` skill） |
| [v1.0](usage-spec-v1.0.md) | 2026-10-27 | 初始版本：仓库重建总结 + 基础使用规范 |

## 变更流程

1. 在 `docs/usage-spec` 分支工作。
2. 大变动 → 复制当前版本为新版本号文件，再行修改。
3. 更新 `CHANGELOG.md` 记录本次变更。
4. 提交并推送，重要版本打 tag。
